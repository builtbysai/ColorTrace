# ColorTrace MVP architecture

`@vcd/color-core` is a browser-independent color math and serialization layer. `@vcd/trace-model` is the persisted contract and evidence graph. `apps/extension` owns acquisition, the privacy firewall, local persistence, dashboard, and explicit export.

The browser boundary is intentionally selective: page DOM to allowlisted color evidence to Quick Trace to firewall/schema to IndexedDB. Quick Trace records the chosen property's resolved computed style, the element's property-specific inline declaration when present, directly referenced CSS custom-property names, and a bounded set of matching declarations from page-accessible top-level author style rules. Rule discovery is capped at 32 stylesheets, 512 top-level rules, and 8 persisted matches. Inaccessible stylesheets and truncated searches are recorded as incomplete provenance rather than silently treated as non-matches. It does not copy page source, collect text, recursively crawl arbitrary CSS rule trees, or infer that an observed declaration won the cascade. The dashboard reads validated traces only. No page object, Element reference, arbitrary DOM serialization, or executable data crosses into persistence.

Source and token evidence use explicit confidence. An observed inline declaration or accessible matching author rule can be proven to exist and match without being proven to determine the computed value. CSSOM evidence is therefore candidate provenance unless the product can account for the complete relevant cascade. Conditional/nested rules, cascade layers/scopes, animations and transitions, user/user-agent origins, and inaccessible stylesheets can make a winning-rule claim unknowable from the current permission-free acquisition path. A referenced CSS custom property is surfaced only as a token candidate unless stronger project/source evidence later proves semantic token identity. ColorTrace does not manufacture authored provenance or token identity from value similarity alone.

Resolved CSS/style evidence remains distinct from rendered-pixel appearance. Quick Trace uses computed style and therefore cannot claim to measure compositing, anti-aliasing, filters, backdrop effects, color-management output, or actual screen pixels.

The unlisted inspector keeps page code dormant until explicit invocation. Background code performs injection and persistence. Dashboard code runs on an extension origin and has no page authority.
